# 완료 조건과 단계별 목표

목표는 바이오 분석 소프트웨어를 **로컬에서 입력·분석·검토·내보낼 수 있고, 실패와 근거를 재현할 수 있는 연구 웹앱**이다. 임의의 95% 대신 다음 수용 조건을 사용한다. 인터넷 다사용자 서비스와 독립 전문가의 취약점 정확도 평가는 별도 범위다.

| 단계 | 완료 조건 | 확인 근거 |
|---|---|---|
| 1. 판정 | 지원 버전 규칙의 경계를 검사하고 미지원 범위는 보류 | `test_versions.py`, 72개 공개 출처 통제 사례 |
| 2. 사용 흐름 | Case와 SBOM+OSV 업로드 → 미리보기 → 실행 → 근거 조회 → ZIP | 실제 브라우저의 합성 배포 검증, 웹 API 테스트 |
| 3. 저장·복구 | 재시작·중복 요청·취소·재시도 및 기존 검토 유지 | 큐 테스트, 0.3 고정 산출물·검토 해시 호환성 테스트 |
| 4. 모델 실행 | 실제 모델 호출을 규칙 기반으로 대체하지 않고 실패·사용량 보존 | Responses/chat transport 테스트와 별도 live 실험 원자료 |
| 5. 연구 보고 | 같은 입력·모델·예산의 단일/멀티 비교, 원자료·실패·한계 공개 | 사전 고정 6사례 패널, 같은 모델, 2회 반복, 호출 trace |
| 6. 배포 검증 | 패키지 설치·CLI·Windows/Linux CI·비밀정보 검사 | `VALIDATION.md`와 공개 CI 커밋·실행 링크 |

## 이 완료 범위에 포함하지 않는 주장

- fixture 일치율을 실제 배포 취약점 정확도로 해석하지 않는다.
- 작은 한 모델 패널로 멀티에이전트의 일반적 우위나 과학적 추론 능력을 입증하지 않는다.
- 파일 해시를 전자서명, 로컬 검토자 문자열을 인증된 신원으로 소개하지 않는다.
- Maven·Conda·Debian·Git 등 지원하지 않는 버전을 자동으로 안전하다고 처리하지 않는다.
- 실제 운영 배포, 패치 실행, 다사용자 인증·HA까지 완료했다고 표시하지 않는다.

추가 개발은 독립 라벨 확장, ecosystem 지원 확대, 실제 배포의 인증·서명으로 나눈다. 이 항목들은 테스트 수를 늘려 대체할 수 없다.

## 0.4.2 로컬 연구 베타 판정

핵심 수용 항목은 구현·검증 자료를 갖췄다. 판정 경계 12개 추가 사례, 실제 모델 48회 비교, 비동기 UI 상태 5개 검사, 모바일 검토창과 오류 안내를 보완했다. Windows/Linux × Python 3.11/3.12의 4개 CI 환경이 모두 통과했다. 이 로컬 연구 베타의 6개 수용 항목을 충족했으며 상세 링크는 VALIDATION.md에 기록했다. 제품 전체에 임의의 완성률을 부여하지 않는다.

독립 전문가 정확도 검증과 다사용자 서비스 운영은 이 로컬 연구 베타의 완료 여부와 별도로 표시한다. 해당 항목은 현재 완료되지 않았다.
