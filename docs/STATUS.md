# 완성도 기준과 남은 작업

현재 공개본은 **로컬 단일 사용자 연구 작업 공간 0.4**다. 핵심 웹앱 동선과 실제 모델 비교를 구현·검증했다. 95%라는 임의 수치 대신 [수용 기준](RELEASE_ACCEPTANCE.md)별 근거를 기록한다.

| 기준 | 상태 | 근거 / 한계 |
|---|---|---|
| 입력 → 실행 → 근거 → 검토 → 내보내기 | 구현·검증 | 예제·Case·SBOM+OSV 직접 업로드, 무저장 미리보기, 원문·그래프·ZIP |
| 지속 실행·중복 요청·복구 | 구현·검증 | SQLite 큐, 소유 잠금, crash recovery, 멱등 요청, 취소·새 ID 재시도 |
| 입력·출처·판정 검증 | 구현·검증 | 전체 128개 자동 테스트; 독립 verifier |
| 로컬 브라우저 경계 | 구현·검증 | Host/Origin·CSRF·cookie·CSP·요청 크기 제한·비밀값 미반환 |
| 버전 범위 | 구현·검증 | PyPI PEP 440 / strict SemVer; 미지원·오류는 보류; 과거 2.0 기록 호환 |
| 공개 사례·실행 시간 | 측정 | 72개 출처 기반 계약 사례, 90회 핵심 시간 측정; 독립 정확도 아님 |
| 실제 모델 비교 | 실행·원자료 공개 | 동일 모델 24회; 단일 12/12, 멀티 11/12 최종 통과; 멀티 우수성 없음 |
| 패키지·교차 환경 | 검증 기록 공개 | 버전별 실제 검사와 CI 링크는 VALIDATION.md 참조 |
| 독립 연구 정확도 | 미완료 | 전문가 held-out 라벨, 여러 모델·ecosystem·정상 업무 효용 필요 |
| 다사용자 운영·인증·서명 | 범위 밖 / 미완료 | reviewer 문자열은 인증된 신원 아님; 인터넷 서비스 운영 검증 없음 |

다음 우선순위는 ① 근거 참조 오류를 줄이는 모델 계약 개선과 별도 패널 재평가 ② 생물정보학 환경의 독립 평가 라벨 ③ 추가 ecosystem·패키지 별칭 지원 ④ 필요 시 인증·접근 제어를 갖춘 팀 서비스다. 현재 fixture 통과율·자동 테스트 수·모델 최종 통과율을 제품 완성률이나 실제 보안 정확도로 환산하지 않는다.
