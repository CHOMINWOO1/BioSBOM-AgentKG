# 완성도 기준과 남은 작업

95%라는 임의의 숫자 대신 사용자 동선·실행 신뢰성·실험 근거별로 완료 조건을 관리한다. 현재는 **로컬 단일 사용자 연구 작업 공간 0.3**이며, 실제 모델 연구와 외부 서비스 운영까지 완료했다고 표시하지 않는다.

| 기준 | 현재 상태 | 근거 / 남은 일 |
|---|---|---|
| 입력 → 실행 → 근거 열람 → 검토 → 내보내기 | 구현·검증 | 브라우저 전체 흐름, API round trip, 데스크톱·390px 화면 |
| 지속 실행·중복 요청·복구 | 구현·검증 | SQLite 큐, OS 소유 잠금, crash recovery, idempotency, 취소·새 ID 재시도 |
| 잘못된 입력·출처·판정 차단 | 구현·검증 | 독립 verifier 및 93개 전체 테스트 |
| 로컬 브라우저 경계 | 구현·검증 | Host/Origin·CSRF·cookie·CSP·body limit·비밀값 미반환 |
| 공개 사례 검증 | 구현·측정 | OSV 8건, 통제 사례 40개, 실제 배포/독립 label 아님 |
| 실행 시간 | 측정 | 3개 크기 × 30회; HTTP·저장·모델 제외 |
| 실제 모델 paired 비교 | 도구 완성·실험 미실행 | 동일 모델·동일 예산·순서 고정·원자료 저장; 모델 설정 필요 |
| 버전 범위·실제 활용 정확도 | 추가 개발 필요 | fixed 경계도 ambiguous; ecosystem별 해석 및 전문가 corpus 필요 |
| 다사용자 운영·인증·서명 | 범위 밖 / 미완료 | 로컬 reviewer는 인증된 신원이 아님; 인터넷에 직접 공개하지 않음 |

다음 우선순위는 ① 실제 모델 고정 패널 비교 ② PyPI 등 ecosystem별 범위 처리 ③ 생물정보학 환경의 독립 검증 label ④ 필요 시 인증·접근 제어를 갖춘 팀 서비스다. 현재의 source-derived fixture 일치율이나 unit test 개수를 실제 연구 정확도 또는 95% 제품 완성도로 환산하지 않는다.
