# 완성도 기준과 남은 작업

현재 공개본은 **로컬 단일 사용자 연구 작업 공간 0.4.2**다. 핵심 웹앱 동선과 실제 모델 비교를 구현·검증했다. 95%라는 임의 수치 대신 [수용 기준](RELEASE_ACCEPTANCE.md)별 근거를 기록한다.

| 기준 | 상태 | 근거 / 한계 |
|---|---|---|
| 입력 → 실행 → 근거 → 검토 → 내보내기 | 구현·검증 | 예제·Case·SBOM+OSV 직접 업로드, 무저장 미리보기, 원문·그래프·ZIP |
| 지속 실행·중복 요청·복구 | 구현·검증 | SQLite 큐, 소유 잠금, crash recovery, 멱등 요청, 취소·새 ID 재시도 |
| 입력·출처·판정 검증 | 구현·검증 | Python 161개 + UI 상태 5개 자동 테스트; 독립 verifier |
| 로컬 브라우저 경계 | 구현·검증 | Host/Origin·CSRF·cookie·CSP·요청 크기 제한·비밀값 미반환 |
| 버전 범위 | 구현·검증 | PyPI PEP 440 / strict SemVer; 미지원·오류는 보류; 과거 2.0 기록 호환 |

| 외부 검토 자료 평가 | 완료 | 개발 패널과 비중복인 10개 패키지·40개 버전: 외부 기준과 40/40 일치, 오탐·미탐·보류 0. GitHub/OSV 원천 공유, 독립 정확도 아님 |

다음 우선순위는 ① 실제 전문가 참여와 다른 모델·생물정보학 환경의 독립 평가 ② 추가 ecosystem·패키지 별칭 지원이다. 다사용자 운영은 현재 요청 범위에서 제외한다. [외부 기준 평가 보고서](EXTERNAL_REVIEW_EVALUATION.md)에 원자료와 한계를 기록했다. 현재 fixture 통과율·자동 테스트 수·모델 최종 통과율을 제품 완성률이나 실제 보안 정확도로 환산하지 않는다.
